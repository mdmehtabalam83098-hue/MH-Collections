
# MH Collection - Shop Management System

A simple shop management website for ladies' clothing.

## Features

- Product inventory and stock tracking
- Sarees, kurtis, dresses, tops and other clothing
- Purchase and selling price management
- Sales dashboard and sales history
- Customer details and payment methods
- Discount calculation
- A4 invoice printing
- Low-stock alerts
- JSON backup export
- Laptop and mobile-friendly interface

## Technologies

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Setup

1. Keep index.html, style.css, db.js, billing.js,
   app.js and README.md in the same folder.
2. Open index.html in a modern browser.
3. Add products in Products & Stock.
4. Open New Bill to record a sale.
5. Select Save bill and print A4 invoice.
6. Use Export Backup regularly.

## Important Notes

- Data is stored in the current browser on the current device.
- Clearing browser data may delete saved records.
- Export backups regularly and keep them safe.
- This version does not synchronize data between devices.
- This version does not automatically send bills to customers.
- Verify invoice and tax requirements applicable to your shop
  before using it for official accounting.
